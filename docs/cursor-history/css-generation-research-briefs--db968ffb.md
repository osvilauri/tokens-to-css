### 🤖 Asistente

En CSS, una **custom property** es una variable con nombre que empieza por `--`, por ejemplo:

```css
:root {
  --color-primary: #2563eb;
  --space-md: 1rem;
}
```

**`:root`** es el selector del documento (equivalente práctico a `html`). Poner las variables ahí las hace **globales** para toda la app: cualquier regla puede usar `var(--color-primary)`.

En el brief/research, “emitir custom properties en `:root`” significa: el Styles File no genera clases tipo `.btn { … }`, sino un bloque de **variables CSS** que la app consume con `var(--…)`.

Alternativas (por si no quieres eso):
- mismo contenido pero bajo `.theme-dark` / `[data-theme="…"]`  
- valores aplanados sin `var()` entre tokens  
- mixins SCSS → **fuera de V1** (ya lo decidiste)

¿Para V1 quieres salida tipo **variables en `:root`**, o otra forma?
